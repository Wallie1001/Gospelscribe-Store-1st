# Start here

1. Download and unzip this folder somewhere easy, like Documents/gospelscribe-site.
2. Install the Claude desktop app (claude.ai/download) and open the Code tab.
3. Choose this folder as the project folder.
4. Paste this as your first message:

> Read CLAUDE.md and prototype/matthew-journey.html. We're doing Phase 1: the Book of Matthew journey as a section + page on my current Shopify theme, launching in 3 days. I don't code, so walk me through connecting my store step by step.

Claude Code will help you install what's needed (like Shopify CLI) and log in to your store. You do the logins yourself.
